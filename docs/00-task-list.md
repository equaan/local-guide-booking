# Rewritten 15-Task List

Same 15 tasks, same order and same deliverable intent as the course sheet, rewritten for the Python and Kubernetes stack recorded in the Deviations Register.

| # | Task | What I will do | Deliverable |
|--|-------|-------------------------|-------------------|
| 1 | Problem Definition and Scope | Study the need for a Local Guide Booking System; identify users, pain points, stakeholders, constraints and success criteria; freeze a 15-task MVP scope. | Problem statement, stakeholder list, objectives, constraints, approved MVP scope |
| 2 | Agile Planning and DevOps Workflow | Write user stories with acceptance criteria; build a backlog, a Kanban board (GitHub Projects), sprint plan, Definition of Done and a DevOps lifecycle diagram that includes the GitOps flow. | Backlog, task board, sprint plan, Definition of Done, workflow diagram |
| 3 | Requirements, Architecture and Technology Setup | Design the minimum architecture for registration, slot view, booking request, confirmation, cancellation and status tracking. Choose Python and Flask, pip and pytest, SQLite and PostgreSQL, Kubernetes as the target; set up the local environment. | SRS summary, use-case diagram, architecture diagram, data model and API list, working local setup |
| 4 | Git and GitHub Repository Initialization | Create two repositories, app and gitops. Add README, .gitignore, folder structure, issue templates and branch naming rules; commit the initial skeleton with meaningful messages. | Repository URLs, README, initial commits, issues, branch policy |
| 5 | Feature Development with Branching | Implement the first core workflow (accounts and slot availability) on feature branches using add, commit, push, pull and log; raise pull requests, review and merge into develop. | Working feature 1, feature branches, pull requests, review comments, merge evidence |
| 6 | MVP Completion and Git Collaboration | Implement booking request, confirmation, cancellation and status tracking; use a second feature branch; create and resolve a merge conflict; tag a release baseline. | Functional MVP, resolved conflict, tagged version, updated backlog |
| 7 | Jenkins Installation and Continuous Integration Job | Install Jenkins as a container; connect the GitHub repository; create a build job triggered by commit or polling; run pytest; archive the build artefact. | Configured Jenkins job, successful build log, trigger evidence, archived artefact |
| 8 | Pipeline as Code and Deployment | Write a Jenkinsfile with checkout, build, test, package and deploy stages; deploy to a Kubernetes namespace; parameterise at least one environment setting. | Jenkinsfile, successful pipeline run, deployed application screenshot, configuration evidence |
| 9 | Selenium Test Design and Local Execution | Identify five critical user journeys; write Selenium WebDriver tests in Python with assertions, test data and failure screenshots; run locally through pytest. | Test plan, Selenium scripts, local test report, failure-screenshot mechanism |
| 10 | Continuous Testing and Quality Gates in Jenkins | Run Selenium in Jenkins; publish reports; add a SonarQube quality gate; fail the pipeline on test or quality failure; fix a deliberately introduced defect and rerun. | Jenkins test report, SonarQube report, failed pipeline evidence, fix commit, successful rerun |
| 11 | Docker Image and Container Lifecycle | Write a multi-stage, non-root Dockerfile; build, tag, run, map ports, inspect logs, stop, restart and remove containers; scan the image with Trivy. | Dockerfile, image details, command log, Trivy report, running container evidence |
| 12 | Jenkins-Docker Continuous Delivery | Extend the pipeline to build a versioned image, push it to Docker Hub and update the image tag in the GitOps repository after tests and scans pass. | Versioned image, Docker Hub evidence, commit-to-registry pipeline, GitOps tag-update commit |
| 13 | Configuration Management and Cluster Setup | List server prerequisites; write Ansible playbooks (and Terraform if a free cloud VM is used) to configure the target node and install Docker, k3s and Jenkins. | Configuration specification, Ansible playbook, first execution log |
| 14 | Automated Provisioning, GitOps and Reliability Validation | Provision a clean environment with Ansible; deploy through ArgoCD and Helm; rerun automation to show idempotency; run health checks; roll back to the previous stable release by Git revert. | Provisioned node, idempotency evidence, ArgoCD sync and rollback demonstration, health-check result |
| 15 | Final End-to-End Release, Observability, Documentation and Viva | Run the full flow: commit, Jenkins, Sonar, Trivy and Selenium gates, Docker Hub, ArgoCD, Kubernetes; add Prometheus and Grafana dashboards; complete documentation, troubleshooting guide, limitations and future plan. | Final repositories, live demonstration, full report, screenshots or video, presentation, viva |
